01 workflow

Create Filter

Priima naujo filtro duomenis iš svetainės, patikrina dublikatus, įrašo filtrą į Google Sheets ir paleidžia Autogidas scraperį.

  • Trigger: Webhook iš svetainės
  • Duomenų bazė: Filters sheet
  • Output: filtro ID ir scraper startas
02 workflow

Scrape Active Filters & Save Stats

Scrape’ina Autogidas pagal aktyvius filtrus arba konkretų filter_id, atnaujina Listings ir įrašo kainų istorijos snapshot’us.

  • Trigger: Webhook / manual / schedule
  • Output: Listings + ListingPriceHistory
  • Pastaba: OFF būsenoje nauji duomenys nebus renkami
03 workflow

Get Listing Statistics

Pagal filter_id grąžina paskutinę statistiką ir istoriją frontend grafikui. Šį workflow naudoja statistikos skiltis svetainėje.

  • Trigger: Webhook iš frontend
  • Duomenų šaltinis: ListingPriceHistory
  • Output: min / avg / max / history JSON
